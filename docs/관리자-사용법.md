# 관리자 사용법 — gollshow

새 그림을 올리거나, 순서를 바꾸거나, 영화를 더할 때 이 문서를 따라 하시면 됩니다.
코드를 몰라도 됩니다. 컴퓨터·휴대전화 모두 가능합니다.

- 사이트: **https://gollshow.github.io/gollshow-site/** (도메인을 옮긴 뒤에는 https://gollshow.com)
- 관리자: **https://gollshow.github.io/gollshow-site/admin/** (도메인을 옮긴 뒤에는 https://gollshow.com/admin/)

관리자 화면에서 **저장**을 누르면 → GitHub 저장소(`gollshow/gollshow-site`)에 저장되고 → 사이트가 자동으로 다시 만들어져 **약 2~5분 뒤** 사이트에 나타납니다.

왼쪽 메뉴는 이 순서입니다: **사이트 설정 · 회화 · 콩테·파스텔 · 디지털 · 영화 · 음악 · 소개**

## 1. 로그인

처음 한 번은 "토큰"(비밀번호 같은 문자열)이 필요합니다. 이미 쓰던 토큰이 있으면 그대로 쓰면 됩니다.

**토큰 만들기 (처음 한 번, 또는 1년마다)**

1. GitHub에 `gollshow` 계정으로 로그인합니다.
2. **https://github.com/settings/personal-access-tokens/new** 를 엽니다.
3. 이렇게 채웁니다.
   | 항목 | 값 |
   |---|---|
   | Token name | `gollshow 관리자` |
   | Expiration | `Custom…` → 1년 뒤 날짜 |
   | Resource owner | `gollshow` |
   | Repository access | **Only select repositories** → `gollshow/gollshow-site` |
   | Repository permissions → **Contents** | **Read and write** |
4. **Generate token** → `github_pat_…` 로 시작하는 문자열을 복사해 안전한 곳에 보관합니다. (다시 볼 수 없어요. 잃어버리면 새로 만들면 됩니다. 다른 사람에게 보내지 마세요.)

**로그인**

1. 관리자 주소를 엽니다.
2. **액세스 토큰으로 로그인** (Sign In Using Access Token) → 토큰을 붙여 넣고 **로그인**.

한 번 로그인하면 그 브라우저가 기억합니다. 공용 컴퓨터에서는 오른쪽 위 계정 메뉴에서 **로그아웃** 하세요.

## 2. 작품 올리기 (회화 · 콩테·파스텔 · 디지털)

세 분류 모두 똑같이 움직입니다. 예: 왼쪽 **회화** → **회화 작품**을 엽니다.

### 여러 장 한꺼번에 올리기

1. 맨 위 **여러 장 한꺼번에 올리기** 칸에 그림 파일들을 **끌어다 놓거나**, 칸을 눌러 **여러 개를 한꺼번에 고릅니다**.
2. 오른쪽 위 **저장**을 누릅니다.
3. 올린 그림들이 아래 **작품 목록** 맨 위에 한 작품씩 들어가고, 위 칸은 다시 비워집니다.

- 사진은 **2000~3000px 크기의 JPG**를 권장합니다. 올릴 때 자동으로 웹용(WebP, 긴 변 최대 3000px)으로 바뀝니다.
- 사이트는 그림을 원래 크기의 1.5배보다 크게 키우지 않습니다. 큰 파일을 올리면 크게 볼 때 더 크고 선명하게 나옵니다.

### 한 작품씩 더하기

**작품 목록** 위쪽의 **작품 추가** → **이미지**에 파일을 넣고 → **저장**.

### 제목·연도 등 적기

**작품 목록**에서 작품(작은 그림)을 누르면 펼쳐집니다. **이미지 말고는 모두 선택**이에요. 모르는 것은 비워 두세요.

| 칸 | 설명 |
|---|---|
| 이미지 | 꼭 필요합니다 |
| 제목 (영어) / 제목 (한국어) | 비워 두면 사이트에 제목이 나오지 않습니다 (제목 없는 작품이 많아도 괜찮아요). 한국어 제목은 KR 화면에서 보입니다 |
| 연도 · 재료 · 크기 · 메모 | 작품을 크게 볼 때 채운 칸만 캡션으로 나옵니다 |
| 화면 크기 | **S 작게 / M 보통 / L 크게**. 작품 목록 화면에서 얼마나 크게 걸릴지 정합니다. 기본은 M |
| 숨기기 | 켜면 사이트에서 감춰집니다. **지워지지 않아요.** 다시 끄면 돌아옵니다 |
| 과정 영상 | YouTube·Vimeo 주소나 퍼가기(embed) 주소. 넣으면 크게 볼 때 **과정** 버튼이 생깁니다 (지금은 gogo, Pear blossom, willow and water lily) |

다 적었으면 **저장**.

### 순서 바꾸기

**작품 목록**에서 각 작품 왼쪽의 **손잡이(⋮⋮)를 끌어** 원하는 자리에 놓고 → **저장**.
목록의 위에서부터가 사이트에 보이는 순서입니다.

### 작품 지우기

사이트에서 감추기만 하려면 **숨기기**를 켜세요. 정말 지우려면 작품을 펼친 뒤 오른쪽 **⋮** 메뉴 → **삭제** → **저장**.

## 3. 영화 더하기

왼쪽 **영화**. 영화 한 편이 항목 하나입니다.

- **Unheard** 는 알려 주신 사실(2026, Korea AI Contents Awards 공식 선정, 전국 31개 극장 개봉)만 넣고 공개해 두었습니다. **대표 스틸**과 **예고편 주소**, 시놉시스, 크레딧을 채우면 영화 페이지가 완성됩니다. 대표 스틸이 없는 동안에는 물감 위에 제목이 쓰인 화면이 대신 나옵니다.
- **예시 영화 (자리표시)** 를 먼저 열어 보세요. 모든 칸이 채워진 견본이에요. "공개"가 꺼져 있어서 사이트에는 나오지 않습니다. 다 보았으면 지워도 됩니다(⋮ → 삭제).
- 공개된 영화가 하나도 없으면 영화 페이지에는 "Films are on their way. / 영화를 준비하고 있어요." 한 줄만 나옵니다.

**새 영화**

1. 위쪽 **새로 만들기**.
2. 채웁니다.
   - **공개**: 다 채울 때까지 꺼 두세요. 켜고 저장하면 사이트에 나옵니다.
   - **제목 (영어)**: 꼭 적어 주세요. 영화 페이지 주소도 이 제목으로 만들어집니다. **제목 (한국어)** 도 있으면 적어 주세요.
   - **연도**, **상영 시간 (분)**: 숫자만 적으면 "98 min / 98분"으로 나옵니다.
   - **맡은 일**: 예 `Director · Writer` / `감독 · 각본`
   - **한 줄 소개**: 영화 목록에 나오는 한 문장
   - **대표 스틸**: 영화 목록에 가로로 길게(2.39:1) 잘려 보입니다. **대표 스틸에서 살릴 부분**으로 위·아래·왼쪽·오른쪽 중 남길 쪽을 고르세요.
   - **예고편 주소**: YouTube나 Vimeo 주소. 영화 페이지 맨 위에 대표 스틸과 재생 버튼으로 나오고, 누르면 재생됩니다.
   - **시놉시스**: 빈 줄을 넣으면 새 문단.
   - **스틸 (여러 장)**: 여러 장을 한꺼번에 올리고 끌어서 순서를 바꿀 수 있어요. 누르면 크게 보입니다.
   - **크레딧**: 역할(예: 촬영) + 이름 (한 줄에 한 사람)
   - **영화제·수상**, **외부 링크**
3. **저장**.

영화가 여러 편이면 영화 목록 위쪽의 **순서 바꾸기**에서 끌어서 순서를 정할 수 있습니다.

## 4. 첫 화면의 색 바꾸기

왼쪽 **사이트 설정** → **첫 화면 물감 색**.

네 가지 물감(기본: 울트라마린 `#1C2B94`, 버밀리언 `#DB3821`, 비리디언 `#0A6B5C`, 오커 `#F2B833`)이 첫 화면에서 소용돌이칩니다. 색 칸을 눌러 고르거나 색 코드를 적고 **저장**하면 몇 분 뒤 바뀝니다. 원래대로 돌리려면 위의 기본 코드를 다시 적으세요.

같은 곳에서 바꿀 수 있는 것:

- **첫 화면 글자**: 물감 속에서 모여드는 글자 (기본 `gollshow`)
- **메뉴 이름**: 위쪽 메뉴의 영어·한국어 이름
- **연락 이메일**, **Instagram·YouTube 주소**, 그 밖의 링크
- 이름, 하는 일, 검색엔진 설명

## 5. 음악 · 소개

- **음악**: gogolala의 플랫폼 링크(YouTube, Apple Music, Spotify, Tidal). Spotify 주소가 있으면 누르면 열리는 플레이어가 함께 나옵니다.
- **소개**: 페이지의 모든 글을 여기서 고칩니다.
  - **맨 위 큰 글자**: 물감 속에 먹으로 쓰이는 이름 (지금 `goll`)
  - **한 문장**: 이름 아래 크게 놓이는 문장 (영어·한국어)
  - **소개 글**: 빈 줄을 넣으면 새 문단
  - **사진·포스터**와 그 설명 (지금은 2002년 〈Gollshow〉 포스터)
  - **하는 일 (세 칸)**: 영화·회화·음악 칸. 이름, 설명, 누르면 갈 페이지를 고릅니다. 끌어서 순서를 바꿀 수 있어요.
  - **기록 (이력)**: 연도·구분과 내용. **기록 추가**로 더하고, 끌어서 순서를 바꿉니다.
  - **영상 주소**와 설명 (지금은 KBS 〈뉴스광장〉), **주소**
  - 이메일과 Instagram·YouTube는 **사이트 설정**에서 바꿉니다.
