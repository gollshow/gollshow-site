## Round 1 → 2 (art-director review)

- **Bug:** the no-JS fallback 空 rendered unstyled and huge over the opening, and also on About and 404. Cause: Astro's attribute-scoped styles don't reach child components. Fixed by switching to class-based scoping.
- **The opening:** the first ink-bleed used round joins, which looked like a bubble font, and the inner counters showed as hard white rectangles. Three variants were compared side by side (`round` / `miter` / soft halo × three timing curves). Chosen: the serif's sharp corners kept (miter joins) plus a widening soft halo, so the ink soaks into the paper. The thin glyph now fills with the painting *before* the strokes swell, so it stays elegant longer.
- The work framed at the end of the opening was still a blurred placeholder because it lazy-loaded while hidden. It now loads eagerly at low priority.
- "01" read as "0 1" because the label letter-spacing was applied to numerals. Numerals now use tighter tabular tracking.
- Mobile: "콩테 · 파스텔" broke across lines in the rooms list (now nowrap with a smaller size), and the viewer's zoom buttons overlapped the caption (hidden on small screens, where pinch zoom is used). The mobile menu was renumbered so only rooms carry numbers.
- Admin: removed the "Sign In with GitHub" (OAuth) button, which would not work without an OAuth server. Only **access-token** sign-in is offered (`auth_methods: [token]`).
- The /works eyebrow ("HI, I'M GOLL !" in capitals) was replaced by "전체 / All".

## Round 2 → 3

- Lighthouse (mobile): contrast failures on tertiary text, fixed by darkening `--ink-3` in both themes. An `aria-pressed` attribute had leaked onto the list element, and clicking anywhere on the list switched modes; the buttons now use their own `data-mode-btn` attribute.
- The landing had 370 ms of main-thread blocking from the canvas redrawing every frame just to breathe. The resting 空 is now an SVG whose strokes breathe in CSS, and the canvas takes over only when the visitor scrolls or taps 空 (hand-over checked frame by frame). TBT is now 0 ms.
- The rooms-list thumbnail overflowed its cell on mobile, and the music list's top rule ran past the margins. Both fixed.
- OG images: English titles rendered as "De." because opentype.js produced `NaN` path coordinates. Text is now laid out glyph by glyph with its own path serializer.
